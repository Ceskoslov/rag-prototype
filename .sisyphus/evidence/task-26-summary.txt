## LESSONS LEARNED

1. **Health check paths must match actual endpoints**: `/health` vs `/api/v1/health` — wrong path causes perpetual unhealthy state
2. **CORS in both HTTP and HTTPS**: HTTPS apps need OPTIONS handling in HTTPS block
3. **Resource limits prevent host OOM**: Without limits, single service can kill entire system
4. **Seed restart policy**: `restart: "no"` critical to prevent duplicate data ingestion
5. **Dev override composition**: Override files ADD to base config (bind mounts + named volumes coexist)
6. **Frontend health check uses internal port**: Vite dev server is on 5173, not Nginx port 80

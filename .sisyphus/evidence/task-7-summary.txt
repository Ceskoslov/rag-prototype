- Relationships: one-to-many Messages, one-to-many EvaluationResults

**Message Model** (`apps/backend/app/models/message.py`)
- id: auto-increment primary key
- conversation_id: foreign key with CASCADE delete
- role: string (user|assistant|system)
- content: text
- sources: JSON (nullable, for source documents)
- trace: JSON (nullable, for reasoning trace)
- created_at, updated_at: timestamps
- Bidirectional relationship with Conversation

**EvaluationResult Model** (`apps/backend/app/models/evaluation.py`)
- id: auto-increment primary key
- conversation_id: foreign key with CASCADE delete
- faithfulness: Numeric(5,4)
- answer_relevancy: Numeric(5,4)
- context_precision: Numeric(5,4)
- context_recall: Numeric(5,4)
- created_at, updated_at: timestamps

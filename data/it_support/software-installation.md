# Software Installation Request Process

## Overview
SkyWing Airlines prioritizes security and performance when managing software installations across all corporate computing devices. This document outlines the procedures for requesting and installing software on SkyWing-issued laptops.

## Standard Software Library
SkyWing provides a set of pre-approved applications that are available for immediate installation without a formal request:
- **Office Suite**: Microsoft 365 (Word, Excel, PowerPoint, Outlook, Teams, OneDrive)
- **Browsers**: Microsoft Edge (Corporate Standard), Google Chrome (Enterprise), Safari (macOS only)
- **Collaboration**: Slack (Enterprise Grid), Zoom (Premium), Cisco Webex
- **Productivity**: Adobe Acrobat Reader DC, Notepad++, Visual Studio Code (Standard)

## Self-Service Installation
Employees are encouraged to use the automated SkyWing App Store for installing pre-approved applications.
1. **Windows Users**: Open the "Company Portal" application from the Start Menu.
2. **macOS Users**: Open the "SkyWing Self Service" app from the Applications folder.
3. **Installation**: Browse the available catalog and click "Install" for the desired application. Administrative credentials are not required for these apps.

## Requesting Non-Standard Software
If an application is not available in the self-service catalog, a formal "Software Installation Request" (Form IT-404) must be submitted via the IT Service Portal at `it.skywing.com/requests`.

### Request Requirements
- **Business Justification**: A brief explanation of how the software will be used for SkyWing business operations.
- **Cost Center**: The department's cost center for any associated licensing fees.
- **Security Review**: For new or niche applications, the IT Security team will conduct a 7-day security and vulnerability assessment.
- **License Compliance**: IT will verify that the software license is compliant with SkyWing's "Software Asset Management" (SAM) policy.

## Prohibited Software
The following categories of software are strictly prohibited on SkyWing corporate devices:
- **Personal Software**: Non-business games, personal social media apps, and personal backup tools.
- **Peer-to-Peer (P2P)**: Torrent clients, LimeWire, and other file-sharing applications.
- **Cryptocurrency**: Mining software, wallets, and unauthorized trading platforms.
- **Security Tools**: Unauthorized network scanners, password crackers, or packet sniffers.

## Administrative Privileges
Administrative rights are restricted by default to prevent unauthorized configuration changes and malware execution.
- **Temporary Admin Access**: If a specific business task requires administrative rights, employees can request a 2-hour "Privileged Access Session" via the SkyWing PAM (Privileged Access Management) tool.
- **Permanent Admin Access**: Only granted for specific technical roles (e.g., Software Engineers, IT Admins) and requires Senior Management approval.

## Software Updates and Patching
- **Automatic Updates**: All approved software is automatically updated via the SkyWing endpoint management system (Intune or Jamf).
- **Restart Required**: Some security patches require a system restart. Employees have 48 hours to complete the restart before a mandatory, automated reboot is initiated.
- **Version Control**: IT maintains a "N-1" version policy for most critical applications to ensure stability.

## Support and Troubleshooting
For assistance with software installations or if a requested application fails to install, contact the Software Support Team at `sw-support@skywing.com` or extension 5522.
